Welcome

FES is a small game console that lives on your iPad. You make games for it, called carts, right here: you draw the pictures and write the program that moves them. The programs are written in Lua, a small language that is easy to start with. FES works without a network once it is on your Home Screen, and your carts stay on your iPad. This manual starts with a game you can make in ten minutes, then explains each part in turn.

Your first cart

You will draw a small picture and move it around the screen with the arrow keys. A picture the console can move is called a sprite. Its picture is a tile: a square of 8 by 8 pixels.

  1. Press Carts, then New cart. FES opens the new cart's code.
  2. Press Art, then Sprites. The big square shows the tile picked on the sheet. Tap the first tile, top left on the sheet: that is tile 0. It is empty.
  3. Pick any color except the first one, and draw on tile 0 with your finger. The first color is see-through for sprites, so a tile drawn only in it can't be seen.
  4. Press Code. Replace everything in the editor with this program: 
    x, y = 92, 68
function _update()
  if btn(0) then x = x - 1 end
  if btn(1) then x = x + 1 end
  if btn(2) then y = y - 1 end
  if btn(3) then y = y + 1 end
end
function _draw()
  cls()
  spr(0, x, y)
end
  5. Press Run. Your drawing sits in the middle of the screen. Move it with the D-pad or the arrow keys.
  6. Press Save. The cart now waits for you on the shelf, under Carts.

Here is what the program says. The first line makes two variables, x and y, for where the sprite is. FES calls _update 60 times a second: each btn(n) asks whether button n is held, and the sprite moves one pixel that way. Then FES calls _draw: cls() clears the screen and spr(0, x, y) puts tile 0 at x, y. The button numbers are in Buttons.

The console

FES is a pretend console, and like a real one it has fixed limits. Working inside them is part of the fun.

PartWhat it does
Screen192 pixels wide and 144 high. It is drawn 60 times a second; each drawing is a frame.
TilesEvery picture is made of tiles of 8 by 8 pixels. A tile can use 8 colors.
Tile memory256 tiles for the background and 256 more for sprites.
Main paletteA palette is a set of colors. The main palette has 64 colors to choose from, and each cart keeps its own copy, so you can change them.
Palettes8 background palettes and 8 sprite palettes, each 8 colors picked from the main palette. A tile is drawn in one of them. In a sprite, color 0 is see-through.
BackgroundOne map, 32 by 32 tiles, that can scroll. It repeats every 256 pixels in each direction.
SpritesUp to 64 sprites on screen. Each can be flipped sideways or upside down, and drawn behind the map. A scanline is one row of pixels on the screen, and at most 16 sprites show on any one of them.
ButtonsA D-pad, A, B, Start and Select.

Buttons

A program asks about a button by its number, as in btn(4) for A.

NumberButtonKeyboardOn screen
0Left←D-pad left
1Right→D-pad right
2Up↑D-pad up
3Down↓D-pad down
4AZA, the right face button
5BXB, the left face button
6StartEnterStart
7SelectShiftSelect

Numbers 0 to 5 are the same as PICO-8's, and A and B are on PICO-8's keys, Z and X. The D-pad's corners press two directions at once.
