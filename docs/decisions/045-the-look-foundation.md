# 045 The look foundation: tokens, fonts and the pixel grid
Status: accepted (2026-11-16, T42)
Context: M12 restyles FES as a pixel-art device (docs/PHASE2.md, "The look"). Five tasks build on its tokens and two pixel fonts, so the fonts must stay crisp in Safari on an iPad first. The owner approved the colour tokens and Pixel Operator 8, and chose Departure Mono for code after Print Char 21's licence turned out to forbid modification and conversion (decisions 3 and 4, issue #111). The owner tunes the tokens on web/look.html.
Decision: Every colour is a token on :root and every chrome length is a whole number of --u (2px). Fonts are vendored as their authors distribute them, in web/fonts/ with their licence files, and precached by the build's generated list. Pixel Operator 8 by Jayvee Enaguas (HarvettFox96), 2018.10.04-1, CC0 1.0, PixelOperator8.ttf from https://www.dafont.com/pixel-operator.font, sha256 5cccb9ef6cf18977b6e5721d49a1a6e78dd6a6f1c4f69537470f7dc1dc829ffc. Departure Mono by Helena Zhang, 1.500, SIL OFL 1.1, DepartureMono-Regular.woff2 from the v1.500 release of https://github.com/rektdeckard/departure-mono, sha256 5b4fed1daa90708aa9c6ee1190abca9dc22164a1c1def0020386e46b61038cfb. Each font is drawn on its own grid: Pixel Operator 8 has an 8-pixel em with a glyph box of 8, Departure Mono an 11-pixel em with a glyph box of 14. A font's size is a whole multiple of its em (UI 16 px; code 22 px), and its line height is the glyph box at that size plus an even number of font pixels (UI 20 px; code 28 px), never normal. font-synthesis is off so Safari never fakes bold or italic. Boxes holding pixel text sit on whole CSS pixels: no centring that can land on a fraction (place-items: center or translate(-50%) on odd sizes, percentage widths), and no fractional horizontal offsets or letter-spacing, which T42 showed blur glyph edges while WebKit snaps vertical fractions to device pixels. Components are class selectors, applied view by view from T43. web/look.html shows every token, both fonts and every component state. A Playwright spec checks text-on-surface contrast of at least 7:1, 44 px keys, that both fonts load, and that pixel text renders in exactly two colours at 2x; its code sample has no descender glyphs, because FreeType's CFF hinting in Linux WebKit shifts Departure Mono's descender row by about 1% of a device pixel. Safari on the iPad itself is checked by the owner on the PR preview.
Alternatives: Print Char 21 (Kreative Free Use License: no modification or format conversion, and terms that can change); converting Pixel Operator 8 to WOFF2 (needs a converter, saves a few KB of a precached file); a 16 px code font (off Departure Mono's 11 px grid); element selectors for components (would restyle the app before its views are redone); text drawn into canvases by Swift (loses VoiceOver; last resort if the fonts can't be made crisp).
