# 052 Icon keys
Status: accepted (2026-11-17, T48b)
Context: The Art tools were text keys (T47). M12's look (045) wants icon keys drawn on the same pixel grid as the font, tinted by tokens, crisp on the iPad, and no less usable with VoiceOver.
Decision: Icons are 12×12 grids of . and # in scripts/make-ui-icons.js, which refuses any other shape and writes one RGBA PNG per icon to web/ui/<name>.png, checked in; edit a grid and run node scripts/make-ui-icons.js to redraw. One icon pixel is 1u, the size of a Pixel Operator 8 pixel at 16 px, and each PNG is pre-scaled to 4 image pixels per icon pixel (48×48) so that on a 2x iPad the mask is drawn 1:1 and never resampled, whatever WebKit does with image-rendering on masks; image-rendering: pixelated is set too. .icon-key is a 22u square key (1u border, 4u padding, the 12u icon) whose ::before is filled with currentColor through mask-image, chosen by data-icon, so icons are --ink and follow the key's state; ::after stays the toggle LED. Twelve keys use icons: pencil, picker, fill, flip horizontally and vertically, copy, paste, undo, redo, the two imports, and Palettes; block size, bank and palette numbers keep their short text. An icon key has no text and keeps its old visible text as aria-label (Undo and Redo keep Swift's live labels), and has no title: with the name in aria-label, a matching title becomes the description and VoiceOver can read the name twice, and touch Safari shows no tooltip. The script encodes with web/tests/png.js.
Amends: PHASE2 T48's sketch (one sprite sheet, -webkit-mask-image, a title on each key, eleven icons).
Alternatives: one sprite sheet (CSS offsets must follow the script's order); a 12×12 PNG scaled by mask-size (crispness depends on WebKit honouring image-rendering for masks, undocumented); SVG masks (WebKit has rendered SVG masks at the wrong resolution); icon plus visible text (keys several times wider, and the tools strip would wrap again); a title on each key (duplicate speech, no tooltip on touch); one shared picture for both imports (two keys that look the same).
