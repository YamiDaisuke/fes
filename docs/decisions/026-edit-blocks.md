# 026 Edit blocks
Status: accepted (2026-11-13, T20a)
Context: The owner chose an edit area of 1×1, 2×2 or 4×4 tiles (PR #51), shown starting at the selected tile (PLAN T20), so a picture spanning several tiles is drawn as one. The sheet is 16×16 tiles, so a block starting in the last columns or rows would run off it. spr draws one tile, so the editor alone decides which tiles it shows together.
Decision: ArtSelection gains blockSize (1, 2 or 4 tiles per side, default 1). Editors/TileBlock.swift turns the selected tile and the size into a TileBlock whose first tile is the selected one, moved left and up only as far as needed to stay inside the sheet (column min(c, 16 − n), row min(r, 16 − n)), so a block never wraps and always contains the selected tile. The selection itself never moves, so the tile slider still steps through all 256 tiles and a smaller block goes back to the tile chosen. The edit area is a GridLayout of 8n squares whose lines between tiles are a lighter gray (a placeholder in ArtPixel.swift), and the sheet's ring goes around the whole block. Pencil, picker and the pixel cursor (024) use block pixels, 0 to 8n − 1, which TileBlock maps to a tile and its pixel; a stroke clips its line to the block it started in, as 023 clipped it to the tile. The Pixel column and row sliders' max follows the block, a smaller block pulls the cursor inside it, and when the block starts elsewhere the tile slider's aria-valuetext adds "block from tile n". The size is three buttons, "1 by 1", "2 by 2" and "4 by 4", with aria-pressed.
Alternatives: continuing in spr order past the edge (a block at tile 15 would take tile 16 from the start of the next row); wrapping around the sheet (the block's halves at opposite edges); snapping blocks to multiples of n (a picture starting at an odd tile couldn't be edited as one); moving the selection to the block's first tile (the tile slider would stick at column 16 − n, since → would be pulled straight back); clipping the block at the edge (a non-square edit area, and a paste there would drop pixels).
