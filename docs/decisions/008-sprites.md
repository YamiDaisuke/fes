# 008 Sprites
Status: accepted (2026-10-31, T07)
Context: SPEC fixes the sprite hardware (64 sprites, 16 per scanline, flip H/V, priority vs background, own 256 tiles and 8 palettes, color 0 transparent) but not how a sprite is hidden, how positions behave off screen, what priority means against the background, sprite-vs-sprite order, or what counts toward the scanline limit. Decision 004 left background color 0's role to this task.
Decision: The PPU holds separate banks per layer (backgroundTiles/backgroundPalettes, spriteTiles/spritePalettes) and a SpriteTable of 64 Sprite? entries; nil is hidden, and the index wraps at 64. x/y are the top-left in screen pixels, unaffected by background scroll; on write they wrap to 16-bit signed so position arithmetic can't overflow, and tile/palette are masked as in decision 004. Off-screen pixels are clipped, never wrapped to the other edge. Priority is two layers, back to front: background color index 0, behind-background sprites, other background pixels, front sprites; background color 0 stays opaque in its palette color, it is only where behind sprites show. Within a layer the lower table index is in front. Each scanline selects, in table order, up to 16 visible sprites that cover it and have a column on screen (-8 < x < 192); transparent pixels still count, the rest are dropped for that scanline only. Rendering goes scanline by scanline: background row, then that row's sprites.
Alternatives: an isVisible flag or parking sprites off screen (a flag to forget, stale attributes; parking depends on the limit rule); positions wrapping modulo 256 like the Game Boy (a sprite leaving the right edge reappears on the left); unbounded Int positions (overflow-aware comparisons everywhere); the NES/GBC rule that resolves sprite order before priority (a lower-index behind sprite cuts holes in front sprites); background color 0 transparent over a backdrop color (no need until M4's second layer); counting sprites by y alone like the NES and Game Boy (sprites far off screen make visible ones drop out).
