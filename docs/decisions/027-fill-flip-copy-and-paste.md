# 027 Fill, flip, copy and paste
Status: accepted (2026-11-13, T20b)
Context: PLAN T20 adds a fill tool, horizontal and vertical flips, and copy and paste of the edit block (026), with a clipboard that is Swift state kept across carts, not the system clipboard. Every edit must be usable without a pointer (024) and written to the recovery copy once complete (025).
Decision: Fill is a third ArtTool. On a stroke's start it replaces the touched pixel's 4-connected region of the same color index with the selected color, inside the stroke's block and across the tile borders within it; the stroke's later moves do nothing, and a cancel puts the bank back as for the pencil. Fill stays selected after use; the Pixel group's button reads "Fill region" for it. Flip H, Flip V, Copy and Paste are buttons in a Block group. Editors/BlockPixels.swift holds a block's color indices in block order with its size; reading a block, writing one at a selected tile, and flipping work on it, so a flip reads, mirrors and writes back the block and moves its tiles along with their pixels. Copy keeps a BlockPixels in App state that opening a cart leaves alone; it holds indices, so it pastes into either bank. Paste writes a block of the copied size at the selected tile, placed by 026's rule, so at the sheet's edge it moves inward like the edit block instead of wrapping or dropping pixels; the shown block size stays. Paste is disabled until something is copied. Flip, Paste and a keyboard fill end any held stroke first, change the cart, and write the recovery copy once; a pointer fill writes it when its stroke ends; copying and changing the block size write nothing.
Alternatives: 8-connected fill (leaks through diagonal gaps that pixel art uses as outlines); filling on every move (a drag would fill each region crossed); handing back to the pencil after a fill (filling several regions in a row is common, unlike picking); clipping a paste at the edge (drops copied pixels); switching the block size to the pasted size (overrides the user's view on every paste); the system clipboard (PLAN; permissions and a format); ⌘C and ⌘V (they compete with Safari's and CodeMirror's, and the buttons already reach every action).
