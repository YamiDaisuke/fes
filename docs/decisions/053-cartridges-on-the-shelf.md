# 053 Cartridges on the shelf
Status: accepted (2026-11-17, T49)
Context: M12 restyles the shelf (040, 043) as part of the device (045). PHASE2 sketched each entry as a cartridge in a slot, a preview plate above the keys, and the selected cartridge raised and outlined with the focus ring.
Decision: Each entry is a button.cartridge: an aria-hidden label area holding the label canvas (192×144, shown at 96×72 CSS px, one canvas pixel per device pixel on a 2x iPad) or, without a label, the title in the UI font; grip ridges drawn by ::after; and the title on a tape, the button's only readable text, so its accessible name is the cart's name alone. The body is drawn by ::before with the plate's notched clip-path, because a clip-path on the button would clip its focus outline. Swift sets data-tone from the folder's first hex digit mod 5 (mint, sky, pink, butter, coral; tone 0 for the demo's "" and for non-hex folders) and "shell" for a damaged entry; CSS maps tones to tokens. The slot is one row that scrolls horizontally, so Left and Right still move the selection and Up and Down do nothing; scrollIntoView scrolls the slot. Selected is raised 4u with a butter tape; focus is the standard ink and butter ring, so a tapped entry (selected, not focused) and a tabbed one (focused, not selected) look different. A preview plate, aria-hidden, shows the selected entry's canvas copied with drawImage at 2x (4 device pixels per label pixel) and its title; it reads no storage and keeps no images. "No carts yet" shows only after a listing that succeeded with no saved carts. At 1194×834, 1133×744, 834×1194 and 744×1133 the action keys are visible and nothing but the slot scrolls; in smaller windows the shelf view scrolls vertically.
Amends: 043 (entries are cartridges; an entry without a label has no canvas).
Alternatives: the focus ring as the selection mark (selection and focus would look alike); a canvas in every entry hidden when blank; keeping rendered labels in Swift for the preview (about 110 KB of wasm memory per labelled cart); re-reading label.hex on selection; a wrapping grid with Up and Down (more D-pad logic, and the preview plus keys leave room for only one row of cartridges in landscape); clip-path on the button.
