# 050 The Art view layout
Status: accepted (2026-11-17, T47)
Context: The Art view's tools column scrolled on smaller iPads and its palette grids didn't fit (DEBT, T18b QA-4, T20/T21 QA, T26b QA-2). M12 restyles it as part of the device (045). PHASE2 sketched a vertical tool rail between sheet and edit area, and 16u palette swatches with 44 px hit areas.
Decision: At 1194×834, 1133×744, 834×1194 and 744×1133 nothing in the Art view scrolls (with the browser-tab install hint dismissed). #art-view is a grid whose width is rounded down to a whole --u, with one fr track per axis, so every track starts on a whole pixel; canvases sit at the start of their areas, never centred. The sheet area is 201u square, which holds the sheet at zoom 3 on every iPad, and the edit area takes the rest. Landscape: sheet, edit area and a selection plate side by side, and the tools as a strip under the sheet and edit area. Portrait: edit area and tools on top, sheet and selection plate below. Under 744 px wide, two equal columns: the sheet drops to zoom 2 or 1 and the plates scroll. #art-tools holds tool, block size, block actions, history and both imports; #art-selection holds bank, the Palettes toggle, preview palette, colors, the Tile fader and the Pixel group; DOM order is tools, selection, palette editor, which is the visual order in both orientations. Every control is a T42 component (key, switch row, swatch, fader, plate) and keeps its id and accessible name; focus on the shell gets the ink frame from 046. The palette editor keeps 44 px swatches and replaces both canvases instead of the edit area alone, with the entry grid and the main-color picker and Reset on one side and the main palette on the other (stacked in portrait); the color strip and preview palette keys stay visible, so a recolor still shows at once.
Amends: 022 (three columns; sheet zoom no longer grows past 3), 028 (the panel covers the sheet as well as the edit area; Reset sits beside the picker).
Alternatives: a vertical rail between sheet and edit (one 44 px column is ~690 px tall, over 1133×744's 652; two text columns cut the edit area to zoom 31); 16u swatches with overlapping 44 px hit areas (still don't fit the edit area at 1133×744: 556 px wide side by side, ~780 px tall stacked; and overlapping targets aren't 44 px); equal fr tracks for sheet and edit (sheet falls to zoom 2 at 1133, and halves land on fractions); Swift sizing the sheet column (a track sized by its canvas never grows); centring canvases (half-pixel offsets, 045).
