# 019 Offline PWA
Status: accepted (2026-11-05, T15a)
Context: FES must install to the iPad Home Screen and run offline from GitHub Pages, where main lives at the site root and each PR preview at pr/<n>/ on the same origin. Safari evicts storage of sites not on the Home Screen after about 7 days of disuse, and iPadOS has no install API. A stale cached app must never keep running after a deploy.
Decision: web/sw.js precaches the app's files (./, boot.js, App.wasm, the manifest, the icons) with cache: "reload" and answers only those URLs, cache-first; everything else passes through. scripts/build.sh writes a hash of web/dist into sw.js, so every deploy changes it; the browser checks it on navigation and the page calls registration.update() when it becomes visible. A new worker precaches, skips waiting, claims the page and deletes its scope's older caches; a running page offers Reload instead of reloading itself. Main's scope contains every preview's, so a preview's first page can load under main's worker; only a controller running the page's own sw.js counts as an earlier version. Manifest start_url, scope and id are "./" and the worker is registered relatively, so main and every preview are separate apps; Cache Storage is per origin, so cache names carry the scope and a worker deletes only its own. A worker whose sw.js answers 404 (a closed PR's removed preview) unregisters itself and deletes its caches. Icons are generated by scripts/make-icons.js from a pixel-art grid with node:zlib and checked in. In a browser tab, a hint explains the eviction risk and how to Add to Home Screen; Not now hides it for 7 days.
Alternatives: network-first (hangs on bad networks; can pair a new index.html with an old App.wasm); auto-reload on update (interrupts editing); waiting for all tabs to close (a Home Screen app never closes); a git SHA as version (dirty local builds reuse it); absolute /fes/ paths (breaks previews and localhost); icons as Swift golden tests or Playwright screenshots (a generator posing as a test; browser-dependent output).
